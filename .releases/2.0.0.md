**Breaking Changes (TypeScript)**

* Replaced `Decimal` from `decimal.js` with `Big` from `big.js` in the public decimal serializer API.
* Integer serializers now throw `RangeError` for noninteger or out-of-range values instead of coercing them.
* Deserializing an unknown enum mapping now throws `RangeError` instead of returning `null`.
* Custom `Serializer` dependencies must now provide a schema, reader factory and writer factory together.
* Removed public npm subpath exports; package APIs must now be imported from the package root.

**New Features (TypeScript)**

* Added support for selecting `byte` or `int` as the underlying type for enum fields and enum lists.

**Bug Fixes (TypeScript)**

* Fixed decimal serialization to use the .NET decimal binary layout.
* Fixed nullable string and nullable list serialization.
* Fixed character decoding from sliced buffers.
* Fixed schema key reads to restore the reader position after both successful and failed reads.
* Fixed entity snapshot updates and key comparisons.
* Fixed floating-point `NaN` serialization and equality to match the .NET implementation.
* Added validation to prevent invalid buffer sizes and byte values from being silently truncated.

**Technical Enhancements (TypeScript)**

* Updated [`@barchart/common-js`](https://github.com/barchart/common-js) to version 5 and removed obsolete local type declarations.
* Updated other dependencies implicitly.

**Bug Fixes (.NET)**

* Fixed change serialization when items are appended to a primitive list.

**Technical Enhancements (.NET)**

* Updated `Barchart.Common` to version 2.0.1.

**Technical Enhancements**

* Unified the TypeScript and .NET release process.
